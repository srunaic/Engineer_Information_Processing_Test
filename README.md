## 📊 시험 구성 안내

### 1. 📘 필기 실전 모의고사 (200문항 풀세트)
* **1과목: 소프트웨어 설계** (40문항: Q1~Q20, Q101~Q120): 요구사항 분석, UML, 디자인 패턴, SOLID 원칙, 결합도/응집도
* **2과목: 소프트웨어 개발** (40문항: Q21~Q40, Q121~Q140): 트리 순회, Big-O 복잡도, 정렬, 화이트/블랙박스 테스트, 맥케이브 복잡도, 형상관리
* **3과목: 데이터베이스 구축** (40문항: Q41~Q60, Q141~Q160): E-R 모델, 키/무결성, 관계대수, 정규화(1NF~5NF), 트랜잭션 ACID, SQL 문법
* **4과목: 프로그래밍 언어 활용** (40문항: Q61~Q80, Q161~Q180): C언어 포인터/배열, Java 다형성/static, Python 슬라이싱, 스케줄링, 서브넷팅
* **5과목: 정보시스템 구축관리** (40문항: Q81~Q100, Q181~Q200): COCOMO, 기능점수, 암호화(RSA/AES), 네트워크 공격, 클라우드/도커
* **합격 기준**: 전과목 평균 60점 이상 (과목별 과락 40% 미만 방지 실시간 진단 제공)

### 2. ✍️ 실기 실전 모의고사 (60문항 주관식/코드추적)
* **C언어 코드 실행 결과 (15문항)**: 포인터, 2차원 배열 주소 연산, 재귀함수 역추적, 문자열 조작, 비트 연산
* **Java 언어 코드 실행 결과 (15문항)**: 상속과 오버라이딩, 다형성 동적 바인딩, static 공유 변수, 추상 클래스/인터페이스
* **Python 언어 코드 실행 결과 (8문항)**: 슬라이싱, 딕셔너리 컴프리헨션, lambda/filter/map, set 집합 연산
* **SQL 쿼리 작성 및 결과 (10문항)**: GROUP BY HAVING, INNER/OUTER JOIN, DDL ALTER CASCADE, 서브쿼리
* **소프트웨어 공학 & 아키텍처 (6문항)**: 디자인 패턴 식별, 결합도/응집도 평가, 테스트 레벨 매핑
* **네트워크 / 운영체제 / 보안 (6문항)**: 서브넷 마스크 유효 호스트 계산, HRN 우선순위, 암호화 및 네트워크 공격 기법
* **실기 인터랙티브 기능**: 직접 답안을 작성할 수 있는 내 답안 입력창, 모범 정답 및 상세 코드 해설 보기, 자가 채점(⭕ 맞춤 / ❌ 오답) 지원

## ✨ 핵심 시스템 기능

1. **세션 지속성 (Session Persistence) 완벽 탑재**
   - 브라우저나 앱을 닫거나 종료해도 풀던 문제 번호, OMR 마킹 내역, 실기 주관식 답안 입력 내용이 브라우저 로컬 저장소(`localStorage`)에 100% 자동 보존됩니다.
2. **🔄 처음부터 다시 풀기 (Reset) 기능**
   - 언제든 버튼 한 번으로 OMR 및 작성 답안을 초기화하고 1번 문제부터 새 마음으로 모의고사를 시작할 수 있습니다.
3. **4대 통합 학습 뷰**
   - `📘 필기 CBT (200문항)`: 객관식 4지선다 1문제 집중 및 전체 모아보기
   - `✍️ 실기 CBT (60문항)`: 주관식/코드 추적 및 실시간 채점
   - `💡 핵심 요약집`: 필기 5과목 & 실기 프로그래밍 단골 족보 요약
   - `📑 엑셀 족보 검색`: 260문항 통합 키워드 검색 및 다이렉트 풀기 점프
4. **모바일 & PC 반응형 최적화**
   - iOS Safari, Android Chrome, Samsung Internet 등 모든 모바일 환경에서 가로/세로 깨짐 없는 반응형 레이아웃
   - 코드 블록 다크 테마 및 좌우 가로 스크롤(`overflow-x: auto`)
   - 터치 친화적 대형 버튼(44px 이상), PC 방향키(`←`/`→`) 및 숫자키(`1`~`4`) 단축키 지원

## 💾 오프라인 사용 안내 (인터넷 없이 실행)

1. 레포지토리의 `정보처리기사_실전_CBT_교구재_v1.0.0.zip` 파일을 다운로드합니다.
2. 원하는 폴더에 압축을 풉니다.
3. `index.html` 또는 `cbt_player.html` 파일을 더블 클릭하면 크롬, 엣지, 사파리 등 모든 브라우저에서 인터넷 연결 없이도 즉시 실행됩니다.
4. `정보처리기사 시험.xlsx` 파일을 열어 엑셀 내의 **[CBT 바로풀기]** 버튼을 누르면 해당 문제로 즉시 점프합니다.
