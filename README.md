## ✨ 핵심 시스템 기능

1. **4가지 맞춤형 학습 모드 지원**
   - **1문제 집중 모드**: 실전 시험장처럼 한 문제씩 몰입하여 풀고, 즉시 정답 및 1초 암기 공식 팁을 확인합니다.
   - **전체 기출 모아보기**: 100문항 전체를 스크롤하며 취약 유형을 빠르게 점검합니다.
   - **💡 과목별 핵심 요약집**: 5개 과목의 핵심 기출 족보와 빈출 암기 공식을 한눈에 학습합니다.
   - **📑 엑셀 족보 검색 테이블**: 실시간 검색창으로 키워드(예: `C언어`, `정규화`, `SYN`)를 입력하여 연관 문제를 다이렉트로 점검합니다.

2. **실시간 OMR 카드 & 과락 자동 판별기**
   - 100개 번호 그리드로 원하는 문제로 즉시 점프 가능.
   - 현재 총점(100점 만점) 및 각 과목별 득점을 실시간 집계하여 **'과락 주의(8개 미만 과목 표시)'** 및 **'최종 합격권'** 여부를 실시간 진단합니다.

3. **프로그래밍 코드 전용 콘솔 뷰어**
   - C, Java, Python 소스코드와 SQL 질의문이 가독성 높은 다크 콘솔 스타일로 정돈되어 출력됩니다.
   - 모바일 화면에서도 코드가 줄바꿈으로 깨지지 않고 좌우 부드러운 스크롤(`overflow-x: auto`)을 지원합니다.

4. **모바일(iOS / Android) 및 PC 완벽 반응형**
   - 모바일 양옆(좌우) 가로 스크롤 및 핀치 줌(확대/축소)을 허용하여 작은 화면에서도 사료와 코드를 편안하게 열람할 수 있습니다.
   - 모바일 터치 최적화 (버튼 높이 44px 이상, 원터치 정답 체크).
   - PC 키보드 단축키 지원: `←` / `→` (이전/다음 문제 이동), 숫자 `1` ~ `4` (보기 선택).

5. **단일 탭(One-Tab) 스마트 동기화**
   - `BroadcastChannel` 기반으로 엑셀 링크나 새 창에서 문제를 클릭해도 불필요한 중복 탭이 생성되지 않고 기존 창에서 즉시 해당 번호로 부드럽게 전환됩니다.

## 💾 오프라인 사용 안내 (인터넷 없이 실행)

1. 레포지토리의 `정보처리기사_실전_CBT_교구재_v1.0.0.zip` 파일을 다운로드합니다.
2. 원하는 폴더에 압축을 풉니다.
3. `index.html` 또는 `cbt_player.html` 파일을 더블 클릭하면 크롬, 엣지, 사파리 등 모든 브라우저에서 인터넷 연결 없이도 즉시 실행됩니다.
4. `정보처리기사 시험.xlsx` 파일을 열어 엑셀 내의 **[CBT 바로풀기]** 버튼을 누르면 해당 문제로 즉시 점프합니다.
